# SaveBite UI

Production-style React/Vite UI for the SaveBite surplus-food marketplace.

## Run locally

> Do not open `index.html` by double-clicking it. This is a Vite app and must be run through the Vite dev server.

```bash
npm install
npm run dev
```

Then open the local URL printed by Vite (normally `http://localhost:5173`).

## Build

```bash
npm run build
npm run preview
```

## UI modes

Use the top navigation to switch between the customer discovery experience and the seller, delivery, and admin dashboard previews.
